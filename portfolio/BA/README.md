# Contribution Toward the Capstone:

## Why Data Analytics Is Integratable
Data analytics is integratable with the other curricular areas because it has become the focal point and main source of information in all areas and industries. Data management provides reliable and accessible data. Software systems provide applications through which users interact with that information. Networking and cybersecurity provide the infrastructure and protections needed to operate the solution securely. Data analytics connects these areas by turning managed data into information that can support decisions and actions.

## How It Could Be Integrated
My capstone will demonstrate how the four curricular areas can work together in a health insurance appeals application. Data Management will support a small synthetic dataset containing fields such as insurance-company label, service category, denial reason, provider type, and plan type. Business Analytics will use these records to summarize denial patterns across relevant categories. Because the dataset is synthetic and limited in size, the results will be exploratory and will not represent actual insurer activity.

Software Systems will provide a Django web application where users enter information about a denied service and generate, review, and edit an AI assisted appeal letter draft. The application will not automatically submit appeals or make medical or coverage decisions. Cybersecurity principles will guide data minimization, protection of API credentials, and responsible handling of information. A future implementation using real records would require authorized access, appropriate privacy protections, and organizational oversight.
